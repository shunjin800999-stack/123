平安喜乐助手——新电脑独立安装操作指南
适用程序：当前正常运行的 v0.6.116
整理日期：2026年10月8日

本指南用于另一台电脑独立安装、独立运行。
不迁移旧电脑数据库、旧添加任务或旧使用记录。
你可以把目前正常运行的完整程序文件夹压缩后复制过去。


==================================================
软件下载版本、官方链接及安装指令速查
==================================================

【1】Windows系统
推荐：Windows 11，64位Intel/AMD电脑。
当前程序也适用于Windows 10，但本指南的新系统安装优先Windows 11。
已经安装合适Windows的电脑直接使用，无需为了助手重新安装系统。
微软Windows 11官方下载页面：
https://www.microsoft.com/zh-cn/software-download/windows11

【2】Python
推荐下载版本：Python 3.13系列最新维护版，Windows x64安装程序。
当前安装脚本支持范围：Python 3.11～3.14，64位。
官方Windows下载列表：
https://www.python.org/downloads/windows/

进入后找到“Python 3.13.x”（x是官网当时的具体补丁号），
选择该版本的“Download Windows installer (64-bit)”。
文件名应类似：python-3.13.x-amd64.exe。
“amd64”表示普通Intel/AMD的64位电脑，两者都适用。
不要选择32-bit、ARM64、embeddable package或源码包。
Python补丁版本会持续更新，本文不把过时的小版本固定成下载要求。
版本号与下载安装文件以官网实际提供的最新3.13维护版本为准。

如果新电脑已有Python 3.12（64位）且能通过本文检查，也可以继续使用。
Python安装时勾选Add Python to PATH，保留pip、tcl/tk and IDLE及Launcher。

【3】Microsoft Visual C++运行库
下载版本：Visual C++ v14系列，x64，使用微软官方提供的兼容更新版。
官方安装文件直达链接：
https://aka.ms/vs/17/release/vc_redist.x64.exe
官方版本说明与下载入口：
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

下载的文件名：vc_redist.x64.exe。
安装程序显示的版本可能随微软发布更新变化。
普通Intel/AMD的64位Windows选择x64，不选择ARM64。
双击安装；如已有兼容的较新版本，无需卸载。

【4】Telegram Desktop
优先使用与你当前正常电脑一致的Telegram版本。
在旧电脑Telegram的Settings设置页面查看版本号，再决定是否沿用。
本助手目前只记录了助手版本v0.6.116，不能据此推断你的Telegram版本号。

官方桌面版页面：
https://desktop.telegram.org/
官方Windows x64安装版下载入口：
https://telegram.org/dl/desktop/win64
官方Windows x64便携版下载入口：
https://telegram.org/dl/desktop/win64_portable

上面两个直达入口随官方更新提供稳定版，不固定旧版本号。
多独立账号目录时，可使用Windows x64 Portable便携版。
下载后完整解压，每个账号放在自己的目录，分别打开Telegram.exe登录。
如果新机版本与旧机不同，先按后文完成一个账号、人数1的小测试。
Telegram界面语言设为English，不需要把Windows显示语言改成英文。

【5】PowerShell
使用Windows自带的“Windows PowerShell 5.1”。
程序实际调用系统的Windows PowerShell，不要求额外安装PowerShell 7。
在开始菜单搜索“Windows PowerShell”可以打开。
下面安装Windows语言组件时要以管理员身份打开；
其余Python/OCR检查和正式运行一般使用普通用户权限。

【6】OCR依赖版本
你复制的程序目录中的requirements_ocr.txt目前固定为：
rapidocr==3.9.2
onnxruntime==1.30.0
omegaconf==2.3.0

由SETUP_OCR.bat按这个文件自动下载和安装到本目录的.ocr-env。
它还会安装所需的其他依赖，不用手动下载每个Python包。
如果以后requirements_ocr.txt随程序升级变化，以你实际程序文件为准。

--------------------------------------------------
A. 安装Windows英语基础组件和英文OCR语言
--------------------------------------------------

适用：Windows 10/11，需要联网。
操作位置：管理员“Windows PowerShell”。

1. 点击开始菜单，输入Windows PowerShell。
2. 右键“Windows PowerShell”，选择“以管理员身份运行”。
3. 出现Windows授权提示时确认。
4. 先检查组件是否已安装，把下面命令逐行复制进去执行：

Get-WindowsCapability -Online -Name "Language.Basic~~~en-US~0.0.1.0"
Get-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"

5. 如果两项都显示State : Installed，就直接进入后面的复核步骤。
6. 如果基础组件未安装，执行：

Add-WindowsCapability -Online -Name "Language.Basic~~~en-US~0.0.1.0"

7. 如果英文OCR未安装，执行：

Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"

8. 等待每条命令完成，不要在下载期间关闭窗口。
9. 安装后再执行前面的两条Get-WindowsCapability命令。
   应显示State : Installed。
10. 如果安装输出显示RestartNeeded : True，保存工作并重启电脑。
可选：用普通Windows PowerShell检查Windows OCR实际可见的语言：

Add-Type -AssemblyName System.Runtime.WindowsRuntime
[Windows.Media.Ocr.OcrEngine,Windows.Media.Ocr,ContentType=WindowsRuntime] | Out-Null
[Windows.Media.Ocr.OcrEngine]::AvailableRecognizerLanguages | ForEach-Object { $_.LanguageTag }

安装英文OCR后，应能看到en-US或相应的英文语言标记。
若输出空列表或加载类型失败，保留错误文字，不把组件安装状态当成实际识别已通过。

11. 这些命令安装语言识别组件，不会自动把Windows显示界面改为英文。
12. 安装完成后关闭管理员PowerShell。
    正式运行助手与Telegram时保持相同权限，一般都普通双击启动。

出现以下情况时保留完整错误内容：
“需要提升权限”：检查是否确实以管理员身份打开。
下载失败或0x800f开头错误：可能涉及Windows Update、网络或组件来源。
公司受管理电脑、精简系统或部分特殊版本可能由系统策略限制安装。
不要因为这些错误直接修改程序逻辑或关闭系统保护，先核对实际错误。

--------------------------------------------------
B. 核对Python版本、位数和tkinter
--------------------------------------------------

操作位置：普通“命令提示符cmd”或普通“Windows PowerShell”。
逐条执行：

py -3 --version
py -3 -c "import struct, tkinter; print('Python bits:', struct.calcsize('P')*8); print('Tk:', tkinter.TkVersion)"

通过标准：Python版本在3.11～3.14范围内；位数64；tkinter可以导入。
如果py不可用，但已安装带PATH的Python，可以改用：

python --version
python -c "import struct, tkinter; print('Python bits:', struct.calcsize('P')*8); print('Tk:', tkinter.TkVersion)"

若py存在，启动脚本会优先使用py -3，所以必须检查这个命令的实际版本。

--------------------------------------------------
C. 在程序目录安装OCR
--------------------------------------------------

最简单的方式：打开实际程序目录，双击SETUP_OCR.bat。
首次安装需要联网，成功后应出现OCR imports OK和“安装成功”。

也可以在普通Windows PowerShell中运行，以下目录只是示例：

Set-Location "D:\PingAnXiLeAssistant"
.\SETUP_OCR.bat

完成后在同一个普通PowerShell窗口检查：

& ".\.ocr-env\Scripts\python.exe" -c "import rapidocr, onnxruntime, PIL; print('OCR imports OK')"

检查安装的三个主要组件版本：

& ".\.ocr-env\Scripts\python.exe" -c "from importlib.metadata import version; print('rapidocr', version('rapidocr')); print('onnxruntime', version('onnxruntime')); print('omegaconf', version('omegaconf'))"

输出应与requirements_ocr.txt中的版本一致。
如果安装或加载失败，保留同目录的ocr_setup.log。

--------------------------------------------------
D. 启动助手
--------------------------------------------------

在实际程序目录双击START.bat。
或者在普通Windows PowerShell中执行：

Set-Location "D:\PingAnXiLeAssistant"
.\START.bat

所有示例路径都要换成你实际解压、包含app.py和START.bat的目录。
在命令中不要照搬一个电脑上不存在的D盘路径。

说明：本文提供官方发布入口和可复制的检查/安装命令。
具体最新补丁号、实际下载文件及语言安装结果以新电脑现场显示为准。
本文未在你的新电脑执行下载或安装。


==================================================
一、先准备哪些软件和文件
==================================================

1. Windows 10或Windows 11，64位。
   在“设置 → 系统 → 关于 → 系统类型”确认系统是64位。
   当前脚本使用Windows桌面控件和截图，不适用于macOS或Linux。
   如需购买或新装系统，优先选择Windows 11。

2. Python，64位。
   程序的OCR安装脚本支持Python 3.11～3.14（64位）。
   新安装建议选择Python 3.13的最新维护版“Windows installer (64-bit)”。
   前面提到的Python 3.12同样兼容；已经安装合适的3.12无需为了本程序换版本。
   官网：https://www.python.org/downloads/windows/
   不要下载32位、ARM64、源码包或embeddable嵌入版。
   普通Intel/AMD电脑选择“Windows installer (64-bit)”。

3. Microsoft Visual C++运行库，x64。
   用于支持OCR的ONNX Runtime等组件。新电脑建议安装。
   微软官方说明：
   https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
   官方x64安装程序：
   https://aka.ms/vs/17/release/vc_redist.x64.exe
   已安装较新兼容版本时，不需要卸载原版本。

4. Telegram Desktop。
   官方下载：https://desktop.telegram.org/
   尽量使用与你现在正常运行的电脑相同的Telegram版本及账号打开方式。
   新版本的界面控件可能变化，所以新电脑先做小规模测试。
   Telegram界面语言设为English。

5. Windows自带的Windows PowerShell和OCR语言组件。
   助手使用Windows自带的Windows PowerShell，正常Win10/Win11一般已有。
   Windows需要有可用的OCR识别语言，建议增加英语（美国）。
   具体操作见下面第六部分。

6. 你准备复制的完整助手程序压缩包、分配给新电脑的手机号/用户名TXT名单。
   联系人TXT每行一条，例如：
   +5516991234567
   或：
   @example_user

安装Python、Visual C++和OCR时需要联网下载。
正式执行时，Telegram也需要在这台电脑上正常连接并登录。

==================================================
二、旧电脑如何打包
==================================================

1. 在旧电脑停止执行任务，等待当前操作结束后退出助手。
2. 找到实际双击START.bat的程序文件夹。
3. 压缩这个完整程序文件夹，保留子目录结构。
4. 保留所有程序文件，尤其是：
   START.bat
   SETUP_OCR.bat
   setup_ocr.py
   requirements_ocr.txt
   app.py
   所有其他.py文件和.ps1文件
   gold_ingot.ico、gold_ingot.png
   原有说明和第三方许可证文件
5. .ocr-env是旧电脑的Python虚拟环境，不要直接搬到新电脑使用。
   打包时可以不包含.ocr-env。
   __pycache__缓存目录也可以不包含。
6. 不要只把最近下载的补丁包当作完整安装包。
   补丁包需要覆盖在完整程序上；你现在正常运行的完整文件夹才是本次复制的来源。
7. 不复制旧电脑用户目录中的TelegramContactAssistant数据库文件夹。
   本次是新电脑独立使用，使用记录由新电脑重新建立。

如果压缩包里已经包含.ocr-env：
在新电脑解压后，先删除“新电脑解压目录里的.ocr-env”，再安装新OCR环境。
只处理新电脑的副本，旧电脑正常运行的文件保持原样。

==================================================
三、在新电脑解压程序
==================================================

1. 将压缩包复制到新电脑本地磁盘。
2. 建议新建一个容易找到的目录，例如：
   D:\PingAnXiLeAssistant
   没有D盘时也可以用：
   C:\Users\你的Windows用户名\Documents\PingAnXiLeAssistant
3. 在这个目录中完整解压程序。
4. 打开实际包含START.bat和app.py的那一层文件夹。
   文件可能在压缩包解出的下一层子文件夹中，以实际位置为准。
5. 确认START.bat、SETUP_OCR.bat、app.py在同一层，图标文件也在这一层。
6. 在资源管理器中打开“显示文件扩展名”：
   Win11：查看 → 显示 → 文件扩展名。
   Win10：查看 → 勾选“文件扩展名”。
7. 使用你有写入权限的普通本地目录，程序需要在目录里创建OCR环境和安装日志。
   建议正式安装完成后固定使用这个位置；以后移动程序目录，OCR环境可能需要重新安装。

==================================================
四、安装Python及Visual C++运行库
==================================================

安装Python：
1. 从Python官网下载合适的64位Windows安装程序。
2. 双击安装程序。
3. 勾选“Add python.exe to PATH”或“Add Python to PATH”。
4. 点击“Customize installation”（自定义安装）。
5. 保留以下组件：
   pip
   tcl/tk and IDLE（包含tkinter界面组件）
   Python Launcher / py launcher（安装程序提供此选项时保留）
6. 继续Next，使用你有权限的安装路径，完成安装。
7. 多个Python版本已存在时，后面的检查以“py -3”实际调用的版本为准。
   因为START.bat和SETUP_OCR.bat优先使用这个命令。

检查Python：
1. 按Win + R，输入cmd，按回车，打开命令提示符。
2. 输入下面命令后按回车：
   py -3 --version
3. 应显示Python 3.11、3.12、3.13或3.14。
4. 再执行：
   py -3 -c "import struct, tkinter; print('Python bits:', struct.calcsize('P')*8); print('Tk:', tkinter.TkVersion)"
5. “Python bits”应为64，并且应能显示Tk版本，没有import错误。
6. 如果没有py命令，但你安装了正确的Python，可以检查：
   python --version
   python -c "import struct, tkinter; print('Python bits:', struct.calcsize('P')*8); print('Tk:', tkinter.TkVersion)"
   程序在找不到py时会尝试python。
7. 如果py调用了不支持的版本，先通过Python安装程序核对安装版本及Launcher配置，
   保证启动脚本调用的是支持的64位Python，不要只检查桌面快捷方式里的版本。

安装Visual C++：
1. 双击微软官方的vc_redist.x64.exe。
2. 阅读并同意许可条款，点击安装。
3. 若提示已安装兼容的新版本，可以退出安装程序。
4. 如果安装程序要求重启，先保存工作再重启电脑。

==================================================
五、安装这台电脑自己的OCR环境
==================================================

1. 保持新电脑联网。
2. 打开包含START.bat的程序目录。
3. 确认没有沿用旧电脑复制来的.ocr-env目录。
4. 双击SETUP_OCR.bat。
5. 等待安装下载完成，安装过程中不要关闭黑色窗口。
   首次安装用时取决于网络和电脑性能。
6. 程序会自动创建：
   程序目录\.ocr-env
7. 程序按requirements_ocr.txt安装识别组件，不需要你逐个手动安装。
8. 正常完成时，窗口应出现：
   OCR imports OK
   安装成功。
9. 看到成功信息后再关闭窗口。
10. 程序目录中会保存ocr_setup.log，记录本次安装过程。

可选复核：
在命令提示符中切换到实际程序目录，例如：
cd /d D:\PingAnXiLeAssistant
再执行：
.ocr-env\Scripts\python.exe -c "import rapidocr, onnxruntime, PIL; print('OCR imports OK')"
应显示OCR imports OK。

如果安装失败：
保留ocr_setup.log，以及窗口里的完整错误文字。
不要只截取最后一句“依赖安装未完成”。
常见原因包括网络下载失败、Python版本/位数不符合要求、目录无写入权限，
或Visual C++运行库缺失。应根据完整日志处理。

==================================================
六、Windows和Telegram设置
==================================================

A. OCR语言
1. Win11：设置 → 时间和语言 → 语言和区域。
   Win10：设置 → 时间和语言 → 语言。
2. 选择“添加语言”，搜索English (United States) / 英语（美国）。
3. 添加后进入语言选项，安装提供的语言包和基本输入组件。
4. 可以保持Windows显示语言为中文。
5. 如果搜索选人报告明确提示“No installed OCR language is available”，
   或“No installed OCR language”/没有可用OCR语言，需要补装OCR组件。
6. 可在管理员PowerShell中检查英文OCR组件：
   Get-WindowsCapability -Online -Name Language.OCR~~~en-US~0.0.1.0
7. 如果State不是Installed，可安装：
   Add-WindowsCapability -Online -Name Language.OCR~~~en-US~0.0.1.0
   这一步需要联网及管理员权限。
8. 安装完成后关闭管理员PowerShell。助手和Telegram仍建议以普通用户权限运行。
   如果公司或精简版系统不提供该组件，保留系统返回的错误文字再处理。

B. 显示和电源
1. 在“设置 → 系统 → 显示”选择正常分辨率。
2. 初次测试尽量采用与你当前成功电脑相同的显示缩放。
   如果是全新设置，可先尝试1920×1080分辨率、100%缩放，具体取决于屏幕支持。
3. 运行时不要中途改变分辨率、缩放或移动到不同缩放的显示器。
4. 在Windows电源设置中，将接通电源时的自动睡眠设为“从不”。
5. 正式运行时保持桌面解锁，Telegram窗口可见。
6. 远程桌面使用时保持会话连接及桌面可见；断开或锁屏可能影响截图和鼠标操作。
7. 执行过程中避免手动点击正在运行的Telegram窗口、切换账号或修改语言。

C. Telegram账号
1. 打开Telegram Desktop，登录分配给新电脑的账号。
2. Settings → Language → English。
3. 每个执行账号建议采用你当前已经成功的独立程序目录方式。
   例如：
   D:\TelegramAccounts\Account01\Telegram.exe
   D:\TelegramAccounts\Account02\Telegram.exe
   D:\TelegramAccounts\Account03\Telegram.exe
4. 可以使用官方Portable便携版，在不同目录分别打开并登录。
5. 保留Telegram.exe这个程序名称，扫描默认按这个名称识别。
6. 每个账号保持一个独立主窗口，脚本需要能够区分程序路径与进程。
7. 当前不直接接管同一程序中的多个切换账号，也不自动处理自定义-many/-workdir打开方式。
   优先复制你原先成功的账号打开方法。
8. 保持助手和Telegram权限一致，一般都普通双击启动。
9. 需要搜索选人时，把两个目标群置顶，并核对它们位于第一、第二的位置。

==================================================
七、启动助手并准备新名单
==================================================

1. 双击START.bat。
2. 正常启动后，标题应显示：
   平安喜乐助手 - v0.6.116
   并显示金黄色元宝图标。
3. 新电脑会在自己的Windows用户目录建立数据库：
   %LOCALAPPDATA%\TelegramContactAssistant\progress.sqlite3
4. 本次不向该位置复制旧电脑数据库。
5. 如果这台电脑以前没有运行过助手，使用记录会从空数据库开始。
   如果这台电脑此前已经运行过助手，原有数据库不会因为重新解压程序自动清空。
6. 打开“导入名单”。
7. 在手机号或用户名区域点击“读取 TXT 到输入框”，选择对应TXT名单。
   也可以把每行一个的名单粘贴到对应输入框。
8. 读取文件后，再点击“检查数据库并导入”才会保存。
9. 检查有效数量和重复提示。
10. 新数据库的联系人备注编号默认从1开始。
    如你安排了其他编号范围：
    使用记录 → 校准全局起点 → 设置正确的下一个备注编号。
11. 名单起始序号自动领取可用记录，不用手动填写。

==================================================
八、首次测试添加联系人
==================================================

1. 先只打开一个测试账号，准备尚未添加的有效测试联系人。
2. 助手进入“扫描窗口”。
3. 点击“扫描 Telegram 候选窗口”。
4. 在列表中选中这个账号窗口。
5. 可先点击“检查选中窗口控件（只读）”，确认能够生成报告。
6. 进入“账号添加联系人”。
7. 点击“绑定所选窗口并设置人数”。
8. 填写稳定的账号备注，例如账号1，计划人数先设为1。
9. 选择手机号或用户名，保存账号计划。
10. 点击“开始添加联系人计划”。
11. 看顶部“执行步骤日志”，确认任务按照当前步骤执行。
12. 成功后，检查：
    Telegram中的数字备注正确；
    使用记录显示已确认添加成功；
    已成功人数和下一个全局编号正确。
13. 然后再测试2个账号、少量人数，确认账号切换正常。
14. 如出现不明情况，先停止计划，保留现场并“导出添加计划报告”。

添加联系人本身不要求先设置两个置顶群。
正式搜索选人前再完成目标群扫描和核对。

==================================================
九、首次测试搜索选人
==================================================

1. 将两个目标群置顶，核对群①、群②。
2. 扫描窗口，选择要执行的Telegram窗口。
3. 邀请群聊设置 → 批量扫描窗口。
4. 点击“扫描全部窗口及置顶群”。
5. 扫描前程序会尝试自动关闭可识别弹窗、关闭资料面板、清空搜索。
6. 核对每个账号、程序路径、群①、群②。
7. 点击“确认保存所选账号”。
8. 添加计划完成后：
   邀请群聊设置 → 本次添加名单 → 预览当前添加名单。
9. 确认实际成功备注数字后，点击“确认提交名单进行邀请”。
   这个按钮生成选人名单，最终Add仍由你手动点击。
10. 在“置顶群”页面选择相应账号，点击：
    打开群①并选择联系人；
    或打开群②并选择同批联系人。
11. 首次只测试少量联系人，核对选中的实际数字备注。
12. 自动选人完成后，由你在Telegram中点击最终Add确认邀请。
13. 需要高级检测按钮时，点击“显示高级按钮”，
    在“请确认显示测试按钮”的确认框中确认。
14. 如果有问题，点击“暂停选人”，保留当前页面并导出“两群选人报告”。

==================================================
十、常见问题及应该保留的文件
==================================================

1. 双击START.bat提示Python was not found。
   重新检查Python安装、PATH及py/python命令。

2. 提示No module named tkinter。
   使用Python安装程序的Modify功能，补装tcl/tk and IDLE。

3. OCR提示未找到备用识别环境。
   确认是在实际安装OCR的程序目录运行START.bat。
   在这个目录运行SETUP_OCR.bat，等待安装成功。

4. OCR提示DLL load failed或onnxruntime加载失败。
   检查Python是64位、Visual C++ x64运行库是否安装。
   保留ocr_setup.log中的完整错误，不根据单句提示直接更换所有软件。

5. 扫描不到Telegram窗口。
   检查窗口是否打开、程序是否为Telegram.exe、是否最小化，
   并确认助手和Telegram采用相同权限。

6. 置顶群确认失败。
   保留顶部提示和“批量扫描窗口”页面的报告，核对账号与目标群。

7. 添加联系人停止。
   导出“添加计划报告”；不要只发与任务不对应的“两群选人报告”。

8. 搜索选人停止。
   导出“两群选人报告”，保留停止后的Telegram截图。

9. 需要检查窗口控件。
   扫描窗口 → 检查选中窗口控件（只读） → 导出控件报告。

10. 新电脑安装时，需要的基本文件检查：
    有START.bat和app.py；
    有SETUP_OCR.bat、setup_ocr.py、requirements_ocr.txt；
    所有.py和.ps1辅助文件完整；
    有两个金元宝图标文件；
    .ocr-env是新电脑安装生成的；
    能显示OCR imports OK。

==================================================
十一、两台电脑同时独立使用时
==================================================

1. 每台电脑有自己的数据库，当前程序不会跨电脑同步。
2. 为两台电脑分配不同账号和联系人名单，避免重复添加。
3. 如果希望所有电脑的备注编号不重叠，需要你预先安排编号范围，
   并在各自“校准全局起点”中设置。
4. 不要把一个数据库文件放到同步盘，让多台电脑同时写入。
5. 多账号运行时先小规模测试，再逐步增加账号数量，观察CPU和内存占用。
6. 日常通过“导入名单 → 备份数据库”保存各自电脑的进度。

完成检查：
[ ] Windows为64位。
[ ] 支持的64位Python已安装，tkinter能够导入。
[ ] Visual C++ x64运行库已准备。
[ ] OCR安装显示OCR imports OK和安装成功。
[ ] Telegram正常联网，英文界面，账号窗口可区分。
[ ] START.bat正常启动平安喜乐助手。
[ ] 一个账号、人数1的添加测试通过。
[ ] 少量搜索选人测试通过。
[ ] 然后开始正式执行。

本指南根据当前程序启动脚本、OCR安装脚本和界面流程整理。
实际安装结果以新电脑现场检查为准；有错误时保留对应日志和报告。

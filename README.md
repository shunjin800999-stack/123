# TelegramAssistant v0.6.62 补丁

打开TelegramAssistant-v0.6.62-patch.zip并点击Download raw file下载。关闭程序、备份程序和数据库，解压覆盖原程序目录（与START.bat同级），保留数据库与OCR环境。

本版修复旧手机号未确认记录阻止独立用户名队列的问题，旧记录不变、编号不变；未确认用户名仍禁止重复提交并显示名单序号。

启动确认v0.6.62，扫描选择账号窗口，绑定所选窗口并设置人数，名单类型选用户名、用户名起始序号通常填1、首次人数填1；Telegram回到普通聊天页再开始。已有联系人或未知结果会停止并保留记录，不自动重试。

510项测试，499通过、11因缺少图像处理依赖跳过。实际Windows自动添加仍需现场验证。

# TelegramAssistant v0.6.61 用户名快速添加测试版

打开 TelegramAssistant-v0.6.61-patch.zip，点击 Download raw file 下载；备份程序和数据库后，将补丁内全部文件解压覆盖到与START.bat同级目录，保留数据库与OCR环境。

启动确认v0.6.61，导入@用户名名单。账号保持普通聊天页，扫描选中窗口，点击“绑定所选窗口并设置人数”，名单类型选择“用户名”，起始序号填用户名名单自己的序号（通常1），首次计划人数1。保存后开始。

程序直达用户名资料页，核验后打开添加表单，在名字填写当前全局数字编号并清空姓氏，点击Pronto一次，成功后核验用户名、数字名称和编辑/删除标记。无需发送聊天消息，不使用额外API账号凭证。已有联系人与未知错误停止核查。原手机号两次失败换账号与从指定名单序号开始的功能保留。

505项测试：494通过、11缺少图像处理依赖跳过；用户葡萄牙语UI报告回放、Python兼容语法及PowerShell语法解析通过。真实Windows自动操作和英文/中文界面未现场验证；请使用一位尚未添加过的测试联系人，完成后导出添加队列报告。

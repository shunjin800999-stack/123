# TelegramAssistant v0.6.59 补丁

下载：打开仓库中的 `TelegramAssistant-v0.6.59-patch.zip`，点击文件页面的 Download raw file（下载原始文件）按钮。

也可点击 Code → Download ZIP，解压后打开 patch-v0.6.59 文件夹，把其中的文件覆盖到原程序目录；不要将仓库外层目录直接覆盖。

先关闭助手并备份原文件及进度数据库。保留原数据库和 OCR 环境，重新运行 START.bat，确认 v0.6.59。

本补丁把同一账号连续两次已核验的手机号添加失败结果改为跳过该账号，继续队列中的下一账号；成功后清零次数。失败号码保留待核查，编号不递增。

验证：481项测试，470通过、11图像处理依赖相关测试跳过。Windows/Telegram现场操作和中文控件识别未验证。现有识别支持英文及葡萄牙语。
